# Icon sources

- Technology logos (`<name>.svg`): [Devicon](https://github.com/devicons/devicon) v2.16.0, MIT — see `LICENSE`.
- `pwa.svg`, `huggingface.svg`, `webcomponentsdotorg.svg`: [Simple Icons](https://github.com/simple-icons/simple-icons) v13.0.0, CC0 1.0. Fill colors added; `pwa.svg` lightened for contrast.
- Concept glyphs (`lucide-<name>.svg`): [Lucide](https://github.com/lucide-icons/lucide) `lucide-static` v0.468.0, ISC. Stroke set to `#cfdcf0` and width 1.6 so they render on the dark board as `<img>`.
- `json.svg` fill set to `#e6ebf4`, which Devicon leaves unset.
