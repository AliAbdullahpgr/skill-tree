# SkillWeave logo

Created with the built-in imagegen tool. The user's reference motivated a tree silhouette, bold lettering, and small gold stars. The final mark uses an interwoven trunk to connect the name to the skill graph.

Final generation prompt:

> Create a pristine minimalist vector-style website logo on a perfectly solid uniform dark navy background #090c12. Brand text exactly SKILLWEAVE, one line, bold geometric sans serif ivory white. To the left a SMALL compact ivory tree emblem: thick interwoven trunk, just five simple broad branches ending in rounded leaves, three tiny gold four-point stars. The emblem should be SAME HEIGHT as the uppercase text, vertically aligned. Wide horizontal lockup, logo occupies central 90% of canvas width, modest 10% vertical padding. Tree accounts for only 12% of total logo width. Very clean professional flat filled shapes with perfectly smooth sharp contours. Absolutely NO texture, NO splatter, NO distressing, NO grain, NO outlines, NO gradients, NO glow, NO shadows. Lettering is the dominant element. This is the final header logo asset for an RPG skill board, not a mockup. Wide 3:1 composition.

The generated original is preserved in `design/brand/skillweave-original.png` (outside `public/`, so it is not deployed). The header logo is a transparent WebP keyed from that original. Header and icon assets are cropped and resized exports, with the header compressed as WebP. The original has an opaque dark background; it is not a vector asset.
